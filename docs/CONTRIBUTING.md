# Contributing to CollabLab

Thank you for contributing!

The purpose of this repository is to learn professional Git and GitHub collaboration.

---

# Branch Strategy

Never work directly on the `main` branch.

Create a feature branch using the following format:

```text
feature/task-manager
feature/calculator
feature/quiz
```

---

# Commit Message Convention

Use clear and descriptive commit messages.

Examples:

```text
feat: create task card layout
feat: add calculator keyboard support
fix: correct quiz score calculation
style: improve button spacing
refactor: simplify form validation
docs: update README
```

---

# Pull Request Checklist

Before opening a Pull Request, make sure:

* HTML validates correctly.
* CSS is properly formatted.
* JavaScript has no console errors.
* The page is responsive.
* No unnecessary files are included.
* Commit messages are meaningful.

---

# Code Review

The project maintainer will review every Pull Request.

A Pull Request may be:

* Approved
* Request Changes
* Closed

Address all requested changes before requesting another review.

---

# Do Not

* Push directly to `main`
* Modify another developer's assigned lab without permission
* Commit generated files unless requested
* Remove another developer's code

---

# Ask Questions

If you're unsure about a change, ask before making it. Collaboration is part of the learning process.
