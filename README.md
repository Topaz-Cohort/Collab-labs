# 🚀 CollabLab

> **Learn Git. Build Together. Ship Better.**

CollabLab is a collaborative learning platform designed to help beginner frontend developers learn Git, GitHub, and teamwork by building real frontend projects together.

Instead of working on the same files, each developer owns an independent lab while following a professional Git workflow using feature branches and Pull Requests.

---

## 🚧 Your Projects

The design files for each of your project can be found inside each of your project folder.

After you have cloned the repo on your local machine (your laptop), click on the lab folder, then you will find the folder tha has been created for each task.

Do all of your work within your project folder. Do not touch anything outside your project folder so as not to cause any conflict.

## 🌱 Git Workflow

1. Clone the repository
2. Create your feature branch
3. Build your assigned lab
4. Commit your changes
5. Push your branch
6. Open a Pull Request
7. Address review feedback
8. Merge after approval

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Lucide Icons
- Google Fonts (Manrope)

---

## 🤝 Collaboration Rules

- Never push directly to `main`.
- Work only on your assigned lab.
- Keep commits small and meaningful.
- Open a Pull Request for every completed task.
- Wait for review before merging.
